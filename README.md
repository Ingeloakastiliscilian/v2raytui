# v2rayn-tui

Терминальный интерфейс (TUI) к движку [v2rayN](https://github.com/2dust/v2rayN): те же подписки,
ссылки, ядра xray / sing-box, маршрутизация, системный прокси и TUN — плюс быстрый параллельный
замер серверов, фоновые проверки и группа живых быстрых серверов. Работает и без интерфейса (`daemon`).

## Возможности

- **Параллельный замер** задержки и скорости сотен серверов за секунды; тесты не блокируют интерфейс.
- **Фоновый режим**: по расписанию обновляет подписки (не чаще раза в час) и проверяет серверы;
  по желанию — автопереключение на лучший сервер (Failover / Fastest).
- **Группа Alive** — всегда актуальный набор живых серверов быстрее заданного порога. Обновление
  подписок её не трогает; сервер уходит из группы только после нескольких провалов подряд, даже если
  провайдер убрал его из подписки, — пока работает, остаётся. Активный сервер сам не меняется, если
  автопереключение выключено.
- **Работа в фоне**: `v2rayn-tui` открывает интерфейс фонового процесса; закрыли окно — прокси, TUN и
  проверки продолжают работать; открыли снова (в любом терминале, по SSH) — тот же процесс, без
  перезапуска и повторного ввода пароля.
- **TUN** с правилами для приложений; пароль sudo спрашивается при запуске и хранится только в памяти.
- **DNS** — все настройки v2rayN, плюс режим «DNS текущей сети»: прямые запросы и локальные домены сети
  (например, `corp.local`) идут на её DNS; при смене сети всё перестраивается само.
- **Смена сети** отслеживается: проверки начинаются заново, сначала с группы Alive.
- **Проверка страны** при подключении: выходной IP и страна сверяются с названием сервера.
- Импорт ссылок, буфера обмена и QR-кодов, QR-код сервера, редактор маршрутизации.

## Установка

Сборка — `packaging/build.sh` (нужен .NET SDK 10), результат в `dist/`: пакеты `.deb` и архивы
для linux-x64 / arm64. .NET на целевой машине не нужен; ядра и geo-файлы TUI скачает сам.

```bash
# Debian / Ubuntu
sudo apt install ./dist/v2rayn-tui_<версия>_amd64.deb

# любой Linux, без root
tar xzf v2rayn-tui-<версия>-linux-x64.tar.gz && cd v2rayn-tui-<версия>-linux-x64
./install.sh                     # → ~/.local/bin (+ --service: автозапуск daemon; --uninstall: удалить)
```

Для разработки: `packaging/dev-install.sh` — быстрая установка в `~/.local/bin`.

Данные — в `~/.local/share/v2rayn-tui`, отдельно от GUI v2rayN; при первом запуске подписки,
серверы и правила копируются из GUI. Перенос из другого каталога: `v2rayn-tui import-data КАТАЛОГ`.

## Использование

### Клавиши (`F1` — полная справка)

| Клавиша         | Действие                                 | Клавиша     | Действие                            |
| --------------- | ---------------------------------------- | ----------- | ----------------------------------- |
| `Enter`         | подключиться                             | `r` / `t`   | real-ping / tcping                  |
| `Space`, `*`    | отметить / все                           | `s` / `m`   | пинг+скорость / скорость топ-N      |
| `i`             | детали, ссылка, QR-код                   | `Esc` / `x` | остановить свои тесты / все         |
| `c`             | скопировать ссылки                       | `o` / `O`   | сортировка по задержке / скорости   |
| `p`, `v`, `Q`   | импорт: вставка / буфер / QR-картинка    | `u` / `U`   | обновить подписку / все             |
| `Del`, `D`, `X` | удалить / дубликаты / нерабочие          | `a`, `e`    | добавить / изменить подписку        |
| `[ ] { }`       | переместить сервер                       | `/`         | фильтр                              |
| `F3` `F4`       | системный прокси / маршрутизация         | `F5` `F6`   | перезапуск / остановка ядра         |
| `F7`            | TUN                                      | `F8`        | обновить ядра и geo-файлы           |
| `F9`            | фоновая проверка сейчас                  | `b`         | фоновые проверки вкл/выкл           |
| `n`             | проверить подключение                    | `F2`        | настройки                           |
| `q`, `F10`      | выйти или оставить работать в фоне       |             |                                     |

Клавиши работают и в русской раскладке; ссылки можно просто вставить в окно терминала.

### Настройки (`F2`)

Тесты · Фоновый режим · Группа Alive · Локальный прокси (порты, LAN, TUN, логи) · DNS ·
URL и таймауты тестов · Региональный пресет (маршруты, geo-файлы и DNS для страны).

### TUN (`F7`)

Перехватывает весь трафик системы. На Linux нужен пароль sudo: TUI спрашивает его при запуске, если
TUN включён (Esc — без TUN в этом сеансе). `daemon` спросить пароль не может и работает без TUN.

### Маршрутизация (`F4`)

Наборы правил и правила как в v2rayN: домены, IP, порты, протоколы и **приложения** (кнопка
«Добавить запущенное приложение…»; работают в режиме TUN). Импорт/экспорт правил в формате v2rayN.

### Командная строка

```bash
v2rayn-tui status                     # состояние, сеть, ядра
v2rayn-tui sub add 'https://…' --name prov
v2rayn-tui sub update                 # обновить подписки
v2rayn-tui test -m ping               # проверить все серверы
v2rayn-tui use best                   # подключить самый быстрый
v2rayn-tui cycle                      # один фоновый цикл
v2rayn-tui import links.txt           # импорт ссылок
v2rayn-tui core update                # обновить ядра и geo-файлы
v2rayn-tui stop                       # остановить фоновый процесс
```

Автозапуск без интерфейса: `systemctl --user enable --now v2rayn-tui` (юнит — `contrib/v2rayn-tui.service`).

## Что не перенесено из GUI

- Создание сервера по полям протокола (серверы добавляются ссылками).
- Полный шаблон конфига, часть общих настроек (стек/MTU TUN, фрагментация и т.п.), группы серверов,
  статистика трафика, Clash-панели, резервная копия / WebDAV.
